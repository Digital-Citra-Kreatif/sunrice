## Indonesian translated-URL checks (step 7)

- Entry, listing, term, journal, team, neighbourhood and search pages load at the translated addresses (`/id/properti`, `/id/properti/<slug>-id`, `/id/tim`, `/id/kawasan`, `/id/jurnal`, `/id/jurnal/topik/laporan-pasar`, `/id/tipe-properti/vila`, `/id/lokasi/seminyak`, `/id/tentang-kami`, `/id/kontak`, `/id/search`): all 200.
- Language switcher on EN and ID pages: both directions point to the translated address (property, term, neighbourhood, journal, team, listing with filter, search, pages). Filters and query strings are kept.
- Canonical and hreflang: the translated entries have the correct canonical and `hreflang` pairs, and `x-default` is the English page. Fallback pages (untranslated, e.g. `/id/properti/seminyak-beachside-villa`, `/id/services`) canonical to the English URL with no hreflang, per docs/site.md.
- Menus: the Indonesian main, footer and legal menus link to `/id/properti`, `/id/jurnal`, `/id/tim`, `/id/kawasan`, `/id/tentang-kami`, `/id/kontak`, and so on.
- Pagination: `/id/properti?page=2` links are `/id/properti?page=2`, "Halaman" labels; canonical carries the page number.
- Breadcrumbs (JSON-LD): translated addresses and Indonesian names.
- Sitemap `/sitemap.xml`: 105 `<loc>` entries, all 200; 78 `hreflang` alternates, all 200, with `/id/…` addresses for translated items. There is no `/id/sitemap.xml` (404), which is expected.
- Old addresses 301 to the new ones: `/id/properties/villa-arunika-pererenan` and `/id/properties/villa-arunika-pererenan-id` → `/id/properti/villa-arunika-pererenan-id`; `/id/properties/seminyak-beachside-villa` → `/id/properti/seminyak-beachside-villa`; `/id/properties?listing_type=for-sale` → `/id/properti?listing_type=for-sale` (query kept); `/id/journal` → `/id/jurnal`; `/id/journal/topic/market-reports` → `/id/jurnal/topik/laporan-pasar`; `/id/team/…` → `/id/tim/…`; `/id/property-type/vila` → `/id/tipe-properti/vila`; `/id/location/seminyak` → `/id/lokasi/seminyak`; `/id/neighbourhoods/kemang` → `/id/kawasan/kemang`; `/id/contact` → `/id/kontak`; `/id/about` → `/id/tentang-kami`.
