# Sunrice

A Laravel admin panel framework and a CMS built on it.

| Package | What it is |
| --- | --- |
| [`sunrice/admin`](packages/admin) | The admin panel: auth, users and roles, resources, custom React pages, settings, media, activity and security, AI access. Use it on its own in any Laravel app. |
| [`sunrice/cms`](packages/cms) | The CMS, a plugin for the panel: collections, entries, taxonomies, globals, menus, forms, multilingual content and the site side. |

This repository is in early development.
