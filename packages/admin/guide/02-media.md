# Media

**Media** holds the site's images and documents, shared by everything that
uses them.

## Uploading

Drag files onto the library, or use **Upload**. Images get smaller copies
made for the site automatically. Put files in folders to keep them tidy.

## Describing images

Give each image an **alt text**: a short description for people who can't
see it, and for search engines. Describe what matters in the picture, not
"image of".

## Before deleting

A file's details list where it's **used**. Deleting moves it to the trash
first; a file still in use asks before it goes.
