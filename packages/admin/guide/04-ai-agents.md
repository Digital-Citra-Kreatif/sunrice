# AI agents

An AI agent (Claude, ChatGPT and others) can work in the panel for you,
with exactly your permissions: it can't do anything you can't.

## Connecting one

Open **AI access**, create a token, and paste it with the address shown into
your agent's settings. The token is shown once: keep it like a password.
A **read-only** token lets the agent look but not change anything.

## Working with it

Ask in plain words: "draft a post about our new opening hours", "which
pages have no description?". Good agents ask before publishing or
deleting; check what they did in the **Activity log**, where their changes
are marked.

Revoke a token you no longer use, or if it may have been copied.

## Templates, commands and the error log

If your site has the developer tools turned on and you have their
permissions, an agent can also change the site's templates, run a few
maintenance commands (like clearing caches) and read the error log, for
example: "the article page shows an error, find out why and fix it". A
change to a template shows on the site at once. The agent can bring back
the earlier version of a template if you ask.
